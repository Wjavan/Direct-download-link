# FerryLink 1.2.0 修复说明

本批次共 17 个提交，主要修复了三类问题。

**IDM 下载提速**：此前通过 IDM 下载时，无论怎么设置连接数都只能用到 8 个线程，原因是脚本推送链接时漏传了文件大小信息，IDM 拿不到总大小就无法并行切分。现在已修复，大文件下载速度可以正常跑满带宽。

**百度网盘下载体验**：点击 API 下载链接后改为直接交给浏览器下载，与其他网盘行为一致；百度网盘超过 50MB 的文件会弹出明确提示（推荐用 IDM / Aria2 / cURL），不再点击后毫无反应。该限制仅存在于百度网盘，其他网盘不受影响。

**API 下载弹窗重排**：文件名不再被固定宽度截断，改为与下载链接按 1:3 分配空间，悬停可查看完整文件名；操作按钮区分了主次（IDM 下载为主操作，复制类按钮退为次要），并清理了内部下载器移除后遗留的无效样式。

期间曾尝试引入 `GM_download` 作为替代下载通道，实测受 Tampermonkey 下载白名单限制始终失败，已回退为纯 iframe 方案。所有改动均通过语法校验，Aria2 / cURL / BC 等下载方式未受影响。
