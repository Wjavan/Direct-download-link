# 网盘直链下载助手

支持百度网盘、阿里云盘、天翼云盘、迅雷云盘、夸克网盘、中国移动云盘六大平台的直链下载油猴脚本。登录网页版网盘后，解析出文件的真实下载地址，交给 IDM、Aria2、cURL 等下载器完成下载。

## 功能特性

- 六大网盘直链解析：百度网盘、阿里云盘、天翼云盘、迅雷云盘、夸克网盘、中国移动云盘
- 多种下载模式：API 下载、Aria2 下载、RPC 下载、cURL 下载、镜像加速下载
- 兼容下载器：IDM、XDown、Aria2、NDM、Motrix、终端等
- 配置已内嵌脚本，不依赖任何第三方远程服务器
- 迅雷视频支持云播转码链接下载（文件更小、速度更快）
- 阿里云盘支持增强下载（文件流方式，可动态刷新直链）

## 安装方法

1. 浏览器安装 Tampermonkey（油猴）扩展
2. 打开 `网盘直链下载助手.user.js` 文件，Tampermonkey 会提示安装
3. 点击安装即可

## 使用说明

1. 登录对应网盘的网页版
2. 勾选要下载的文件
3. 点击页面上的"下载助手"按钮
4. 选择下载模式（API / Aria2 / RPC / cURL / 镜像）

## 注意事项

- 各网盘下载直链均有时效性，过期后请重新获取
- 部分网盘对直链下载有限速，属官方限制，脚本无法突破；配合 IDM 等多线程下载器可获得更好速度
- 脚本仅解析下载链接，不存储、不转发任何用户数据
